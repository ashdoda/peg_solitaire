## Initial Key Decisions for the Peg Solitaire Project

- **Object Oriented Programming Language:** Python
- **GUI Library:** React/jsx
- **IDE:** VS Code
- **xUnit:** pytest/Jest

### Programming Style Guides

- Google's Python Style Guide: <https://google.github.io/styleguide/pyguide.html>
- Airbnb's React/JSX Style Guide: <https://github.com/airbnb/javascript/tree/master/react>
- Apple's Human Interface Guidelines: <https://developer.apple.com/design/human-interface-guidelines>
  - The HIG will be used as a reference and inspiration for the GUI rather than a solid rule
